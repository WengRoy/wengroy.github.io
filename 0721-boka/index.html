Windows 弱點掃描與入侵偵測 工具箱

疑似遭入侵的 Windows 主機該怎麼查？快速診斷完全用系統內建指令、免安裝任何軟體——直接看 ③④ 分頁，逐塊複製貼到命令提示字元就能跑。想再做完整弱掃或深入鑑識時，② 分頁才有進階工具可選裝。每塊指令都有 📋 複製 鈕，刻意拆小、一行註解一行指令，方便你改參數。

最後更新：2026-07-21　·　適用：Windows 10 / 11 / Server　·　指令中的 192.168.1.50 等為範例，請自行替換

🛡️ 動手之前，先記住這五條鐵律

對「疑似已被入侵」的機器，錯誤的操作順序會讓災情擴大。下面五條決定你會不會把自己的帳號也一起賠進去。

1

可疑機器 = 敵營

假設它已被植入側錄／後門。你在上面打的任何帳密、存下的任何 token，都可能被偷走。

2

憑證不落地

你的 Claude、GCP、網域管理員密碼，絕不登入這台可疑機器。操作端要用另一台乾淨機。

3

鑑識前先保全

要深入取證前，先斷網隔離、再做磁碟快照／記憶體映像，別直接動現場。

4

熱點 ≠ 隔離

給可疑機任何對外網路，惡意程式就能回連 C2、外傳資料。真隔離＝完全斷網。

5

確認被入侵 → 重灌

後門很難保證清乾淨。在上面跑指令主要是取證、釐清災情，不是把它救回來繼續用。

⚠️ 最常見的致命錯誤 在可疑主機上「登入你自己的雲端帳號來裝工具幫忙查」——這是把整串信任憑證端進敵營。正確做法是：乾淨機當指揮官、可疑機只跑不需登入的獨立工具，把輸出檔帶回乾淨機分析。

🔍 系統盤點 & 弱點面（本機執行）

以下全部是 Windows 內建指令、免安裝任何軟體。在可疑機開「命令提示字元（以系統管理員身分執行）」，逐塊複製貼上，摸清這台的底細、缺哪些修補、開了哪些門。建議把輸出存檔帶回乾淨機分析——每塊最後都可加 > 檔名.txt 導出。

🖥️ 系統資訊與修補程式全貌CMD
REM 一次看系統版本、開機時間、已裝的修補程式（找缺哪些更新）
systeminfo
🔎 看什麼：「Hotfix(s)」清單有多舊？作業系統版本是否已過期停止支援？這決定弱點面大小。
🩹 只列修補程式編號與安裝日期CMD
REM 精簡列出已安裝的 KB 修補程式與安裝日期
wmic qfe get HotFixID,InstalledOn
🔎 看什麼：最後一筆安裝日期若在好幾個月前 → 長期沒更新，高風險。（新版 Windows 若無 wmic，改用第④分頁的 PowerShell Get-HotFix。）
🔌 所有網路連線與監聽埠（含 PID）CMD
REM 列出所有連線／監聽的連接埠與對應程式 PID
netstat -ano
🔎 看什麼：有沒有連到陌生外部 IP（ESTABLISHED）？有沒有不該開的監聽埠（LISTENING）？記下可疑的 PID 去第④頁對照程序。
🧱 防火牆三種設定檔狀態CMD
REM 顯示網域／私人／公用三種防火牆設定檔是否開啟
netsh advfirewall show allprofiles
🔎 看什麼：State 是否為 ON？被關掉的防火牆常是攻擊者手筆。
🧷 列出所有服務狀態CMD
REM 列出所有服務與狀態（找被停用的防護服務／可疑新服務）
sc query type=service state=all
🔎 看什麼：防毒／Defender／Windows Update 服務被停？出現名稱怪異的新服務？服務是常見的持久化手法。
📂 開放的共用資料夾CMD
REM 列出這台開出去的網路共用（找被打開的分享）
net share
🔎 看什麼：除了預設的 ADMIN$ C$ IPC$，有沒有多出你不認得的共用？那可能是外洩／橫向移動管道。
🌐 網路設定 / ARP / 路由CMD
REM 網路設定（IP、DNS、閘道）
ipconfig /all
REM ARP 快取：內網有哪些機器跟它講過話
arp -a
REM 路由表：找有沒有被塞奇怪的靜態路由
route print
🔎 看什麼：DNS 被改成陌生位址？路由表多出奇怪條目？ARP 表有沒有你不認得的內網機器（找橫向移動目標）。
🗂️ 一鍵把系統盤點結果全導出到桌面
📤 全部輸出成一份 txt（帶回乾淨機看）CMD
REM 依序把各項結果寫進目前資料夾的 recon.txt（第一行用 > 建檔，其餘用 >> 附加）
systeminfo > recon.txt
netstat -ano >> recon.txt
sc query type=service state=all >> recon.txt
net share >> recon.txt
ipconfig /all >> recon.txt
arp -a >> recon.txt
route print >> recon.txt
🔎 用途：跑完會在你目前命令列所在的資料夾（通常是 C:\Users\你的帳號）產生 recon.txt，用隨身碟帶回乾淨機，或貼給 AI 幫你判讀，避免在可疑機上久留。想確認位置可先打 cd 看目前路徑。
🕵️ 入侵偵測 / 鑑識（找有沒有被種後門）

弱掃是「找門有沒有鎖」，這頁是「找小偷是不是已經在屋裡」。一樣免安裝、全用系統內建指令，在系統管理員命令提示字元逐塊複製。重點放在帳號、持久化（自啟／排程）、可疑程序、登入紀錄。

👤 帳號與權限
列出本機所有帳號CMD
REM 列出本機所有使用者帳號（找有沒有被偷加的帳號）
net user
🔎 看什麼：出現你不認得的帳號（尤其像亂碼、或偽裝成 admin/support/sql）→ 高度可疑。新增一個看似正常的帳號長期潛伏，是最經典的後門手法。
列出系統管理員群組成員CMD
REM 列出本機 Administrators 群組成員（找被偷偷提權的帳號）
net localgroup administrators
🔎 看什麼：管理員名單裡有沒有多出帳號？一般使用者被加進管理員 = 提權跡象。
目前登入 / RDP 工作階段CMD
REM 目前登入中的使用者工作階段
query user
REM 遠端桌面(RDP)工作階段
query session
🔎 看什麼：有沒有你以外的人正透過 RDP 連著？攻擊者常留著遠端桌面。
🔁 持久化：開機自啟與排程
登錄檔開機自動執行項CMD
REM 機器層級開機自啟項
reg query "HKLM\Software\Microsoft\Windows\CurrentVersion\Run"
REM 使用者層級開機自啟項
reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Run"
🔎 看什麼：指向 Temp、AppData、ProgramData 或亂碼路徑的自啟項 → 很可能是後門。這是最常見的持久化位置。
詳列所有排程工作CMD
REM 詳列所有排程工作（找被塞的後門排程）
schtasks /query /fo LIST /v
🔎 看什麼：「作者」不是微軟／你、動作是跑 powershell -enc、cmd /c、下載執行的排程 → 高度可疑。攻擊者愛用排程做定時回連。
wmic 列出開機啟動項CMD
REM 列出開機啟動項的名稱與執行路徑
wmic startup get Caption,Command
🔎 看什麼：路徑落在使用者資料夾／暫存區的啟動項要特別留意。（最完整的自啟稽核請用下載清單的 Autoruns。）
🧟 可疑程序與網路連線
程序清單 + 對應服務CMD
REM 列出所有執行中程序與其掛載的服務
tasklist /svc
🔎 看什麼：把第③頁 netstat 記下的可疑 PID 拿來對照，看是哪支程式在連外。svchost.exe 出現在怪路徑、或 PID 對不上服務 = 偽裝跡象。
只看「已建立」的對外連線CMD
REM 只列出已建立的連線，快速抓連外行為
netstat -ano | findstr ESTABLISHED
🔎 看什麼：連到你不認得的公網 IP（非公司、非常見雲服務）→ 可能是 C2 回連。把 IP 拿去 VirusTotal／AbuseIPDB 查信譽。
DNS 解析快取CMD
REM 顯示 DNS 快取（看這台最近解析過哪些網域）
ipconfig /displaydns
🔎 看什麼：解析過的可疑網域（動態 DNS、亂碼網域、known-bad）留下連外痕跡。
📜 事件日誌：登入與異常
匯出「安全性」事件日誌CMD
REM 把安全性事件日誌匯出成 evtx 到目前資料夾（帶回乾淨機用 Chainsaw/Hayabusa 分析）
wevtutil epl Security Security.evtx
🔎 用途：會在目前資料夾產生 Security.evtx，帶回乾淨機用進階工具 Chainsaw／Hayabusa 套 Sigma 規則掃威脅，比在本機肉眼看快得多。（這步是進階分析，只匯出檔案本身不用裝軟體。）
查登入成功 / 失敗 / 新建帳號事件CMD
REM 最近 20 筆登入成功（EventID 4624）
wevtutil qe Security /q:"*[System[(EventID=4624)]]" /c:20 /rd:true /f:text
REM 最近 20 筆登入失敗（EventID 4625，暴力破解跡象）
wevtutil qe Security /q:"*[System[(EventID=4625)]]" /c:20 /rd:true /f:text
REM 最近 20 筆新建使用者帳號（EventID 4720）
wevtutil qe Security /q:"*[System[(EventID=4720)]]" /c:20 /rd:true /f:text
🔎 看什麼：大量 4625（登入失敗）＝有人在猜密碼；4720（新建帳號）不是你做的＝有人建了帳號；4624 裡出現陌生來源 IP／帳號＝已被登入。
🦠 用內建 Defender 直接全盤掃
更新定義檔並執行完整掃描CMD
REM 先更新 Defender 病毒定義檔
"%ProgramFiles%\Windows Defender\MpCmdRun.exe" -SignatureUpdate
REM 執行完整掃描（ScanType 2 = 全盤）
"%ProgramFiles%\Windows Defender\MpCmdRun.exe" -Scan -ScanType 2
🔎 用途：不用裝任何東西，用系統內建 Defender 就能全盤掃一次。免費、方便，作為第一道快篩。
⚡ PowerShell 加值指令（開 PowerShell 系統管理員執行）
⚠️ 下面這幾塊是 PowerShell 語法（註解用 #），要在「Windows PowerShell（系統管理員）」視窗跑，不是命令提示字元。
Defender 狀態 / 完整掃描PowerShell
# 顯示 Defender 即時防護狀態與最後掃描時間
Get-MpComputerStatus
# 執行 Defender 完整掃描
Start-MpScan -ScanType FullScan
🔎 看什麼：RealTimeProtectionEnabled 若為 False → 即時防護被關，是入侵常見動作。
修補程式（比 wmic 準）PowerShell
# 列出已安裝修補程式，依安裝日期新到舊排序
Get-HotFix | Sort-Object InstalledOn -Descending
🔎 看什麼：最新一筆更新的日期，判斷這台多久沒打補丁。
PowerShell 歷史命令（攻擊者愛用 PS）PowerShell
# 讀取目前使用者的 PowerShell 命令歷史
Get-Content (Get-PSReadlineOption).HistorySavePath
🔎 看什麼：出現 IEX、DownloadString、-EncodedCommand、base64 字串 → 典型攻擊指令，代表這台被拿來下載執行惡意程式。
找最近 7 天被修改的可執行檔PowerShell
# 找 C 槽最近 7 天內被寫入的執行檔（可疑落地檔）
Get-ChildItem C:\ -Include *.exe,*.dll,*.ps1,*.bat -Recurse -ErrorAction SilentlyContinue | Where-Object { $_.LastWriteTime -gt (Get-Date).AddDays(-7) } | Select-Object FullName,LastWriteTime
🔎 看什麼：落在 Temp／AppData／ProgramData／使用者下載區的近期新檔，是後門常見落地點。對照建立時間跟入侵時間軸。
🌐 從乾淨機遠端掃描這台

當可疑機接在同一個網段（同一台 router / Wi-Fi），你可以從乾淨機（Mac / Linux / 另一台 Windows）對它的內網 IP 掃描。指令中的 192.168.1.50 請換成目標主機實際 IP。

⚠️ 遠端掃描代表可疑機還連著網路。若你要做的是鑑識取證，請先隔離；遠端掃描適合用在「初步盤點」或「已放到隔離網段」的情況。
找目標的 IP（先確認掃誰）Terminal
# 掃整個網段找出存活主機（把網段換成你的，如 192.168.1.0/24）
nmap -sn 192.168.1.0/24
🔎 用途：不確定那台 Windows 的 IP 時，先用這條列出網段內所有活著的主機與主機名。
服務版本與作業系統指紋Terminal
# 探測目標開了哪些服務、版本、作業系統（需 root/管理員）
nmap -sV -O 192.168.1.50
🔎 看什麼：開放的服務版本是否老舊、有沒有不該對外的服務（RDP 3389、SMB 445）。
內建漏洞腳本快篩Terminal
# 用 NSE 內建 vuln 腳本快速篩已知漏洞
nmap --script vuln 192.168.1.50
🔎 用途：快速抓出常見 CVE。這是「快篩」不是「完整掃」，完整請用 Nessus。
專掃 Windows SMB 弱點Terminal
# 專門檢查 SMB 服務的已知漏洞（如永恆之藍等）
nmap --script smb-vuln* -p 445 192.168.1.50
🔎 看什麼：SMB（445）是 Windows 橫向移動最愛的入口，這條專門查它有沒有已知的高危漏洞。
🛡️ Nessus 認證掃描（最準，建議收尾用）
為什麼要「認證掃描」？ 非認證掃描只從外面看得到的埠猜漏洞，會漏很多；認證掃描用一組管理員帳密登入進去，逐一比對修補程式版本，準確度高得多。你人在機器旁、有管理員權限，強烈建議走認證掃描。
🧭 Nessus 認證掃描設定重點（GUI 操作）：
1. 乾淨機安裝 Nessus Essentials → 新增 Basic Network Scan
2. Targets 填目標內網 IP（如 192.168.1.50）
3. Credentials → Windows 填一組本機管理員帳密
4. 目標端需開：File and Printer Sharing（SMB 445）、Remote Registry 服務、允許掃描來源通過防火牆
5. 跑完看報告依 Critical → High → Medium 排序修補
🧭 建議處置流程（一條龍）

止血：切斷源頭

若源頭是外洩的雲端金鑰（如被盜的 service account key），先停用／刪除該金鑰、輪換憑證，並關掉雲端連回內網的 VPN／防火牆規則，切斷跳板路徑。

隔離可疑 Windows

拔網路線／關 Wi-Fi，讓它離線。避免攻擊者繼續橫向移動或看到你在動他。

保全證據

深入取證前先做磁碟快照／WinPmem 記憶體映像。動了現場就回不去。

本機鑑識

照第③④分頁跑：帳號、自啟、排程、程序、連線、事件日誌、Defender 全盤掃。輸出檔帶回乾淨機。

弱點掃描補洞

第⑤分頁 Nessus 認證掃描，把該打的補丁、該關的服務、該改的弱密碼處理掉。

全面輪換憑證

內網相關帳密、VPN、雲端使用者、管理員密碼全部換掉。假設它們都可能已外洩。

重建乾淨主機

確認被入侵的機器，標準處置是重灌（wipe & reinstall）。很難 100% 保證後門清乾淨，別冒險留用。

🔎 判讀速查表：什麼算正常、什麼有鬼
檢查項正常長這樣有鬼的跡象
本機帳號 net user只有你認得的帳號多出亂碼／偽裝名（admin、support、sql…）帳號
管理員群組只有應有的管理員一般帳號被加進 Administrators
對外連線 netstat連到已知雲端／公司服務連陌生公網 IP、非常見埠、持續回連
開機自啟 / 排程微軟與已知軟體指向 Temp/AppData、跑 powershell -enc 的項目
防火牆 / Defender開啟、即時防護 On被關閉、服務被停用
登入事件你本人的登入紀錄大量 4625 失敗、陌生 IP 的 4624、你沒做的 4720
PowerShell 歷史空的或你的正常指令IEX / DownloadString / EncodedCommand / base64
近期落地檔你安裝的軟體Temp/AppData 下近期新增的 exe/dll/ps1
