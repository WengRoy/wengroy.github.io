這張圖告訴你聲音從吉他「跑去哪裡、被誰處理、最後從哪聽到」。看懂這條鏈，你就懂錄音了。

什麼是 AU Plugin？

AU = Audio Unit，是 Apple 自家的 plugin 格式，GarageBand、Logic Pro 只吃 AU，不吃 Windows 的 VST。我推薦的免費 plugin 全部都有 AU 版本，所以可以直接掛進 GarageBand。

★什麼是 AU (Audio Units)？

因為這個詞會一直出現，這邊單獨開一節仔細講清楚。

📦 一句話定義

AU (Audio Units) 是 Apple 在 macOS 系統內建的「音訊外掛程式格式」，由 Apple 開發、屬於 Core Audio 框架的一部分。它讓第三方開發者可以做出「擴大機模擬、效果器、合成器、EQ、壓縮器」等模組，讓 GarageBand、Logic Pro 等 DAW 直接載入使用。

🌍 三大主流 Plugin 格式比較

格式 全名 開發者 支援平台 誰會用
AU Audio Units Apple 僅 macOS / iOS GarageBand、Logic Pro
VST / VST3 Virtual Studio Technology Steinberg Windows / Mac / Linux Cubase、Ableton、Reaper、FL Studio
AAX Avid Audio eXtension Avid Windows / Mac Pro Tools

🤔 為什麼 GarageBand 不吃 VST？

因為 VST 是 Steinberg 的格式，而 Apple 想要在 macOS 上維持自己的標準（也方便和 iOS 整合），所以 GarageBand 跟 Logic Pro 都只認 AU。換句話說，你在 GarageBand 上看不到任何 VST plugin，就算你裝了也不會出現。

幸好 99% 的商業 plugin 都會同時推出三種格式（AU + VST + AAX），所以你下載時只要確認「有 AU 版本」就好。我推薦的那六款免費 plugin 全部都支援 AU。

📁 AU Plugin 安裝在哪裡？

所有 AU plugin 都放在這兩個固定路徑（系統會自動掃描）：

  • /Library/Audio/Plug-Ins/Components/ ← 系統共用（所有使用者）
  • ~/Library/Audio/Plug-Ins/Components/ ← 個人使用者

每個 plugin 是一個 .component 檔案。你不需要手動操作，下載官方安裝程式（.pkg）執行即可，安裝程式會自動放到正確位置。

🔄 第一次裝完看不到 plugin 怎麼辦？

GarageBand 第一次啟動時會「掃描 + 驗證」所有 AU plugin（叫做 AU Validation），這個過程要幾秒到幾分鐘。如果還是找不到：

  1. 完全離開 GarageBand（⌘ + Q）
  2. 打開「Logic Pro 內建的 AU Manager」（如果沒有 Logic 就跳過）
  3. 重開 GarageBand，再到 Smart Controls → Plug-ins → Audio Units 列表找
  4. 還是不行 → 確認是否裝到 Components/ 資料夾、是否有重開機

💡 一個有趣的小知識

AU vs VST 哪個比較好？

音質上沒有差別。AU 跟 VST 只是「打包格式」不同，裡面跑的 DSP 演算法是一樣的。Blue Cat Free Amp 的 AU 版跟 VST 版聽起來完全一樣，差別只在「哪個 DAW 認得它」。所以你不用糾結格式問題，只要在 Mac 上錄音，認 AU 就對了。

2GarageBand 與 Plugin 怎麼合作？

GarageBand 本身就有內建吉他擴大機模擬（Amp Designer），但音色種類有限。第三方 AU plugin 的角色，就是「取代或加掛」在這條音色處理鏈上，讓你用更專業的音色。

🔧 安裝 → 使用流程

  1. 下載 plugin 安裝檔（.pkg 或 .dmg），執行安裝。安裝程式會自動把 plugin 放到 /Library/Audio/Plug-Ins/Components/
  2. 打開 GarageBand → 新增專案 → 選 「Empty Project」（空白專案）
  3. 新增軌道時選 「Audio — Guitar」（電吉他軌），輸入來源選你的 audio interface
  4. 點軌道 → 按左下角 「Smart Controls」（或按 B 鍵）→ 點 「Plug-ins」 區塊
  5. 點 「+」 → 「Audio Units」 → 找到剛剛安裝的 plugin（例如 IK Multimedia → AmpliTube 5）
  6. 建議把 GarageBand 內建的 Amp Designer / Pedalboard 關掉（按 Bypass），避免兩層 amp 疊在一起
  7. 按 R 鍵 開始錄音 → 用 plugin 的音色彈奏 → 錄完按空白鍵停止

常見錯誤：聲音變兩次破音、糊成一團

因為你沒有關掉 GarageBand 內建的 Amp Designer，等於訊號被破音兩次。記得：插了第三方 AU 之後，把內建的擴大機模擬 bypass 掉。

🎚️ Input Monitoring（即時監聽）

錄音時想聽到自己彈出來的音色，要打開「Input Monitoring」：軌道頭上有個喇叭 icon（橘色那個），點亮它。如果延遲很大，到 GarageBand 偏好設定 → Audio/MIDI → Buffer Size 調小到 64 或 128。

📅 一週速成計畫：七天錄出第一首 Demo

  1. Day 1 — 設備與環境：搜尋 YouTube「Focusrite Scarlett Solo 開箱 教學」，把硬體接好、Hi-Z 鈕按下去、確認 Mac 抓得到介面
  2. Day 2 — GarageBand 入門：看 Mixodus Music 或 璃思維 的 GarageBand 教學，建立第一個 Audio Track、學會錄音與停止
  3. Day 3 — 安裝 Plugin：下載 Blue Cat Free Amp + AmpliTube 5 CS，掛進 GarageBand，bypass 內建 Amp Designer，調出第一個自己喜歡的音色
  4. Day 4 — 錄一段 riff：選一段你會彈的 8 小節 riff（自己寫或翻彈都可），錄 3 次取最好的一次。重點是「習慣聽自己彈奏的錄音」
  5. Day 5 — 加鼓 + Bass：用 GarageBand 內建 Drummer 加一段鼓，再用內建貝斯軌做簡單低音線。看 LiSWEi 的 Drummer 教學
  6. Day 6 — 疊軌 + Solo：在原本的 riff 上再錄一軌（雙吉他左右 pan 開），如果想加 solo 就再開一軌錄 solo
  7. Day 7 — 簡單混音 + 輸出：調整音量平衡、加一點 reverb、Master 掛上限制器（內建即可）→ Share → Export Song to Disk → MP3。你的第一首 Demo 完成！

Roy 的建議

不要想著「先學完所有理論再動手」。第一週就強迫自己錄出一首 demo（哪怕很爛），比花一個月看教學影片但什麼都沒錄要有用 100 倍。錄音這件事 70% 是肌肉記憶，30% 才是技術。

7新手最常踩的坑

  1. 沒按 Hi-Z / Inst 鈕：吉他直接插但音色超乾 → 先檢查介面上有沒有 Hi-Z 開關
  2. 延遲太大（latency）：buffer size 設太高 → GarageBand 偏好設定改 64 或 128 samples
  3. 聽不到自己聲音：軌道頭上的 Input Monitoring 喇叭 icon 要點亮
  4. 音色變兩層破音：忘了把 GarageBand 內建 Amp Designer bypass 掉
  5. 用筆電喇叭聽混音：請務必用耳機，不然永遠調不準
  6. 裝完 plugin 看不到：重開 GarageBand 一次，AU 第一次掃描要時間
