遠端控制網路架構全解析

Claude Code Remote Control × TeamViewer × AnyDesk × Chrome Remote Desktop——四種「讓兩台電腦找到彼此」的完全不同哲學，以及 headless Mac Studio 在 WiFi 不穩定環境下的最佳方案。

🏗 四種「讓兩台電腦找到彼此」的哲學
🤖

Claude Code Remote Control

Outbound-Only HTTPS Relay

桌機對 Anthropic API 發出 outbound HTTPS 請求，手機透過同一個 API relay 接入。不開任何 inbound port，不需要 VPN，不需要改防火牆——就像瀏覽器載入網頁的連線模式。（2026/02/25 Anthropic 正式發佈）

Port：HTTPS 443 only（outbound）
加密：TLS 端對端，Anthropic relay 也看不到內容
📡

TeamViewer

Master + Router 兩段式

兩端先向 master*.teamviewer.com 做金鑰交換與驗證，再連到地理最近的 router*.teamviewer.com。70% 的情況可建立 P2P 直連（UDP/TCP）；其餘 30% 經由 router server relay。

Port：5938（TCP/UDP）主力，fallback 443/80
加密：TLS + RSA 2048（relay 端不可讀）
⚡

AnyDesk

P2P 優先 + Relay 備援

透過 AnyDesk 全球網路協商連線，盡量建立 UDP/TCP 直連，不通才走 relay。DeskRT codec 只傳畫面差異 pixels（非全畫面），100 kb/s 即可運作，延遲 <16ms。

Port：443、6568（TCP），7070（LAN P2P）
加密：TLS 1.2 + RSA 2048
🔵

Chrome Remote Desktop

WebRTC 三模（ICE 協商）

基於 WebRTC + ICE 協議，自動嘗試三種模式：① Direct（直接 IP）→ ② STUN（穿 NAT）→ ③ TURN/Relay（走 Google 機房）。UDP 優先於 TCP（效能更好）。

Port：443 + 3478（TCP+UDP）
加密：DTLS（WebRTC 標準）
🌐 三種網路拓撲模型
工具 核心協議 Headless 支援 WiFi 斷線恢復 純 Terminal 適用
Claude Code RC HTTPS relay ✅ 佳 ⚠ 易逾時 ✅ 最適合
TeamViewer TCP relay / P2P ✅ 有 ⚡ 重連數秒 ❌ 畫面傳輸
AnyDesk P2P / relay DeskRT ✅ 有 ⚡ 重連數秒 ❌ 畫面傳輸
Chrome Remote Desktop WebRTC ICE ⚡ 需設定 ❌ 重協商慢 ❌ 畫面傳輸
Tailscale + mosh + tmux WireGuard + UDP ✅ 專為此設計 ✅ 自動重連 ✅ 最佳
🖥 場景：headless Mac Studio + 不穩定 WiFi + 手機控制 Claude Code
關鍵限制：headless（無螢幕）、WiFi 常斷線重連、目標是跑 Claude Code（純 terminal）、控制端是手機或另一台電腦。 這個組合讓「畫面傳輸型」工具（TeamViewer / AnyDesk / Chrome Remote Desktop）全部不是最佳選擇——它們是拿大砲打蚊子。
推薦組合的四層架構說明

🏆 最佳組合：Tailscale + mosh + tmux + Claude Code

L3
Claude Code（任務執行層）

在 tmux session 裡跑 claude 指令或 Remote Control，任務本身與網路連線完全解耦。就算 mosh 斷了重連，Claude Code 在 Mac Studio 上繼續跑，不會知道連線曾中斷過。

L2
tmux（session 持久層）

讓所有 terminal session 在 server 端永久存活。tmux new -s claude 建立 session，離線重連後 tmux attach -t claude 就能看到 Claude Code 繼續在跑的畫面。

L1
mosh（連線韌性層）

Mobile Shell，UDP-based，專為不穩定網路設計。mosh user@mac-studio-tailscale-ip 替代 SSH。WiFi 斷掉、IP 換掉，mosh 都能自動重連——不像 SSH 斷線就得重開。

L0
Tailscale（網路穿透層）

基於 WireGuard 的 mesh VPN。Mac Studio 安裝 Tailscale 後自動有固定 IP（100.x.x.x），不管 WiFi 切換幾次、IP 怎麼變，Tailscale IP 永遠不變。手機 / 電腦安裝 Tailscale app 後直接存取。免費版支援 100 台裝置。

🏁 根據情境選架構

🏆 方案 A（推薦）
Tailscale + mosh + tmux

✅ WiFi 斷線自動重連
✅ Claude Code session 永遠存活
✅ 手機 / 電腦都能控制
✅ 免費、開源
✅ headless 零問題

⚠ 需安裝三個工具
⚠ Tailscale 要設開機自啟

安裝：
brew install tailscale mosh tmux

⚡ 方案 B（Claude Code 原生）
Claude Code RC + Tailscale

✅ 官方支援，最少設定
✅ 手機 Claude app 直接控制
✅ Tailscale 確保固定 IP
✅ 加 tmux 防 session 中斷

⚠ 依賴 Anthropic API 可用性
⚠ session 仍可能逾時
⚠ 需要 Claude app（非瀏覽器）

WiFi 不穩建議 Tailscale 墊底，再跑 Claude Code RC。

❌ 方案 C（不推薦）
TeamViewer / AnyDesk / Chrome RD

❌ 設計目的是傳送畫面
❌ headless 需設虛擬螢幕
❌ 對純 terminal 是資源浪費
❌ Chrome RD 重協商最慢
❌ 商業工具有授權費用

例外：若同時需要看 GUI 畫面，AnyDesk 是最輕量選擇（加 Tailscale 穩定連線）。

🎯 這個場景的最終建議 Mac Studio（headless + WiFi 不穩）→ 手機 / 電腦控制 Claude Code

Layer 0：Tailscale — Mac Studio 固定 100.x.x.x IP，手機 / 電腦都裝 Tailscale app
Layer 1：mosh — mosh user@100.x.x.x 替代 SSH，WiFi 斷了自動重連
Layer 2：tmux — 所有 Claude Code session 在 tmux 裡，離線不中斷
Layer 3：Claude Code — 在 tmux 裡跑，WiFi 抖動對它完全透明

安裝完後，WiFi 斷 30 秒、IP 換掉、手機從 WiFi 切到 5G——mosh 會自動重連，打開手機就能繼續接著用。
